02 · Method

From a KNIME workflow to an SVG.

The chart is not a picture. Every bar is a DOM element generated by D3 from the CSV. The same data could be filtered, re-sorted or animated later without redrawing the page.

  1. Prepare the data in KNIME Clean the 2026 TV registrations, group by brand, and export a small two-column CSV.
  2. Load and type the data d3.csv() reads the file and a row conversion function turns the count from a string into a number.
  3. Bind data to rectangles Each brand becomes a <g> containing a bar, a brand label and a value label.
  4. Scale to the canvas A linear scale maps counts to width; a band scale maps brands to vertical positions.
  5. Label and test Add the axis, value labels and a hover tooltip. Resize the window to check the responsive SVG.
js/main.js 
// Exercise 4.6 — scales make the chart fit the canvas
const xScale = d3.scaleLinear()
  .domain([0, d3.max(data, d => d.count) * 1.08])
  .range([0, innerWidth]);

const yScale = d3.scaleBand()
  .domain(data.map(d => d.brand))
  .range([0, innerHeight])
  .padding(0.18);

// Exercise 4.7 — a group keeps each bar and its labels together
const barAndLabel = chart
  .selectAll("g.bar-row")
  .data(data)
  .join("g")
  .attr("class", "bar-row")
  .attr("transform", d => `translate(0, ${yScale(d.brand)})`);
