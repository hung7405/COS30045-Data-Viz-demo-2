Week 4 · Exercise 4.2

Change the page with D3.

D3 is not only for charts. It can select any element in the DOM, change its style, append new content and create SVG shapes. This page is the live result of the Exercise 4.2 code.

d3.select append style SVG rectangle

The code

Three selections, three changes

The code lives in js/exercise-4.2.js. It is deliberately separate from js/main.js: Exercise 4.3 asks us to delete the Exercise 4.2 experiments before starting the bar chart, so keeping them on their own page preserves the work without polluting the final chart code.

js/exercise-4.2.js 
// Step 2 — select the heading and change its style
d3.select("#demo-heading")
  .style("color", "green");

// Step 3 — append a paragraph to the container
d3.select("#demo-container")
  .append("p")
  .text("Purchasing a low energy consumption TV will help with your energy bills!");

// Step 4 — append an SVG rectangle and give it attributes
d3.select("#demo-svg")
  .append("rect")
  .attr("x", 50)
  .attr("y", 50)
  .attr("width", 100)
  .attr("height", 30)
  .style("fill", "green");

What to notice: d3.select() returns a selection. .style(), .attr(), .append() and .text() are chained because each method returns the selection it was called on. The browser's Elements panel shows the result in the live DOM.

Experiment

Try selectAll

The exercise suggests trying d3.selectAll("div"). If the page had several <div> elements, selectAll() would return all of them and .append("p") would add a paragraph to each one. This page uses IDs for precision so the demo does not accidentally add text to the layout wrappers.

In the console, try:

Browser console 
d3.selectAll(".demo-container")
  .append("p")
  .text("A second paragraph, added from the console.");

Reload the page to reset the demo. The next exercise removes these experiments and starts the bar chart with a clean main.js.
